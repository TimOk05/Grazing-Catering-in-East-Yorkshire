# Gather & Graze Yorkshire — website concept

A bespoke one-page website concept for a grazing caterer serving Hull and East Yorkshire.

## Local development

```bash
npm install
npm start
```

Open `http://127.0.0.1:4173`.

## Browser tests

```bash
npm test
```

## Content note

The concept uses only publicly verifiable business information. Current menus, prices, dietary accommodations and availability should be confirmed with Gather & Graze Yorkshire before production launch. The food photography was generated specifically for this concept and is not presented as the business's existing work.
